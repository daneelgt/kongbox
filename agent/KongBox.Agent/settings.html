Atalhos

O celular só envia o id; o comando fica neste PC. Um atalho abre um programa ou URL, aperta teclas, digita texto ou roda uma macro.

Regras

Quando algo acontece no PC, o KONGBOX reage: notifica, troca de página, roda um atalho ou grava um valor.

Webhooks

Qualquer coisa que faz uma requisição HTTP pode colocar dados no painel. Deste PC não precisa de chave.

Integrações

O que o KONGBOX lê do seu PC e da sua conta. Cada cartão diz se está funcionando e, se não estiver, o que fazer.

Claudecotas de uso (sessão de 5 h e semanal) e sessões do Claude Code
  1. Instale o Claude Code no PC: npm install -g @anthropic-ai/claude-code
  2. Abra um terminal, rode claude e entre com a sua conta Pro ou Max.
  3. Pronto: o KONGBOX lê o seu uso sozinho. O login dura umas 8 horas; quando vencer, rode claude de novo no terminal.
Codexcotas e sessões, lidas dos arquivos locais do Codex (nada sai do PC)
  1. Instale o Codex CLI: npm install -g @openai/codex
  2. Rode codex e entre com a sua conta ChatGPT.
  3. Use o Codex uma vez: as cotas aparecem assim que ele grava a primeira sessão.
Notificações do WindowsWhatsApp, Discord, e-mail… aparecem no celular; toque para abrir o app no PC
  1. Ligue o interruptor e salve. Não precisa instalar nada: o KONGBOX lê a Central de Notificações do Windows.
  2. Os apps precisam ter notificações ligadas no Windows (Configurações › Sistema › Notificações).
