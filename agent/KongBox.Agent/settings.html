Atalhos

O celular só envia o id; o comando fica neste PC. Um atalho abre um programa ou URL, aperta teclas, digita texto ou roda uma macro.

Regras

Quando algo acontece no PC, o KONGBOX reage: notifica, troca de página, roda um atalho ou grava um valor.

Webhooks

Qualquer coisa que faz uma requisição HTTP pode colocar dados no painel. Deste PC não precisa de chave.
